# Демо подсистемы №1 «Жизнеобеспечение» в Wokwi (VS Code)

Пины по распиновке спеки v3: TFT CS 5 / DC 16 / RST 17 / SCK 18 / MISO 19 / MOSI 23,
DHT22 на 27 и DS18B20 на 26 (обе линии с подтяжкой 4,7 кОм к 3V3), реле обогревателя 25,
серво заслонки 32, зуммер 13, кнопка «Подтвердить» 14.
Реле и серво питаются от 5V. Оранжевый светодиод «ОБОГРЕВ» за контактом реле — только для наглядности.

1. Собрать прошивку: двойной клик по `build.bat` (или `.\build.bat` в терминале этой папки).
   Скрипт копирует логику из `firmware/`, ставит библиотеки и кладёт прошивку в `build/`.
   Нужны Arduino IDE 2 и ядро esp32.
2. VS Code → File → Open Folder → `wokwi/life_support_demo` (папка, где лежит `wokwi.toml`).
3. F1 → «Wokwi: Start Simulator».

После правки кода — снова `build.bat`, затем перезапуск симулятора.

На старте: воздух 22 °C, влажность 45 %, обшивка −10 °C — НОРМА.
Показания меняются кликом по датчику во время симуляции (ползунки).
Уровень меняется, только если новое значение держится 2 с; возврат вниз — с запасом 1 °C / 2 %.

Как проверять:
- DHT22, температура 17 °C → сразу обогрев ВКЛ (реле щёлкает, светодиод горит), через 2 с ВНИМАНИЕ;
  обогрев выключится при 20 °C;
- DHT22, температура 14 °C → АВАРИЯ (плашка мигает красным раз в 0,5 с, непрерывный звук);
- DHT22, температура 27 °C → заслонка 90°, ВНИМАНИЕ; закроется при 24 °C; 31 °C → АВАРИЯ;
- DHT22, влажность 25 % или 70 % → ВНИМАНИЕ; 15 % или 85 % → АВАРИЯ;
- DS18B20 ниже −30 °C → ВНИМАНИЕ «Обшивка переохлаждена»;
- «ПОДТВЕРДИТЬ» во время АВАРИИ — звук выключается, красный остаётся;
  авария второго параметра или новая авария после возврата снова включает звук.

У каждого параметра на экране своя цветная метка, плашка показывает уровень подсистемы (максимум).
Журнал в Serial (Wokwi Terminal): строка на каждую смену уровня `мм:сс | подсистема | уровень | значение`,
плюс строки о включении обогрева и повороте заслонки.
