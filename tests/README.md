# Юнит-тесты логики подсистем

Прогон без железа: логика подсистем (`wokwi/sketch/*.cpp`) компилируется
компьютерным g++ с заглушками Arduino (`tests/stubs/`) и тестируется
сценариями из кейса (пороги, выдержка 2 с, гистерезис, автореакции).

## Запуск

```sh
g++ -std=c++17 -Wall -I tests/stubs -I wokwi/sketch \
  tests/test_all.cpp tests/stubs/stubs.cpp \
  wokwi/sketch/1_life_support.cpp wokwi/sketch/2_fire.cpp \
  wokwi/sketch/3_airlock.cpp wokwi/sketch/4_meteor.cpp \
  -o tests/test_all
./tests/test_all
```

Ожидается `ALL TESTS PASSED` (11 тестов). Бинарник `tests/test_all[.exe]`
в git не кладётся (см. `.gitignore`).

## Что покрыто

- №2: дым/температура по отдельности — ВНИМАНИЕ; вместе дольше 2 с — АВАРИЯ
  и обесточивание; всплеск < 1 с — без АВАРИИ; «Сброс» только из НОРМЫ.
- №3: внешняя дверь закрывает замок; обе двери дольше 2 с — АВАРИЯ;
  падение давления — ВНИМАНИЕ; < 90 кПа — АВАРИЯ; удар из №4 — ВНИМАНИЕ на 30 с.
- №4: 3 слабых удара — ВНИМАНИЕ; сильный — АВАРИЯ, счётчик, одноразовый флаг
  для №3, новый бит маски для повторного звука; одиночный отсчёт — не удар.
- №1 (регрессия): обогрев при t < 18, заслонка при t > 26.

## Проверка схемы

```sh
python tools/validate.py
```

Сверяет `diagram.json` с распиновкой (спека, раздел 4) и пинами `sketch.ino`:
имена пинов деталей, отсутствие конфликтов GPIO, реле `transistor=pnp`.
Ожидается `OK`.
